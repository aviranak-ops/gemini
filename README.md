# מושן — אתר מובייל עם Image Motion

אתר מובייל (mobile-first, RTL) בקובץ HTML אחד, ללא ספריות חיצוניות.

## אפקטי התנועה

- **Ken Burns** — זום ותזוזה איטיים על תמונת הפתיחה
- **Reveal on scroll** — כותרות וכרטיסים נכנסים באנימציה עם `IntersectionObserver`
- **Inner zoom reveal** — התמונה בתוך כל כרטיס מתכווצת מ־scale(1.18) לגודל מלא בכניסה למסך
- **Parallax** — באנר ציטוט שהרקע שלו נע בקצב שונה מהגלילה
- **Snap gallery** — גלריה אופקית עם `scroll-snap`; התמונה במרכז מקבלת צבע וזום
- **Marquee** — פס טקסט נע אינסופי

## הרצה

פשוט לפתוח את `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

התמונות נוצרות כ־SVG בקוד (אין תלות ברשת), אפשר להחליף אותן בתמונות אמיתיות ע"י שינוי ה־`background-image` של האלמנטים עם `data-img`.

האתר מכבד `prefers-reduced-motion` עבור משתמשים שמעדיפים פחות אנימציות.
